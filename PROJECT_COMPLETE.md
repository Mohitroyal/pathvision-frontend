## 🎨 Design System Quick Reference

### Colors
- **Primary**: #030303 (black), #111111 (cards)
- **Accent**: #C9A84C (gold), #E8C96D (light), #F5DFA0 (lighter)
- **Finance**: #27AE60 (income), #E74C3C (expense)
- **Status**: #1E8A4A (ok), #D4830A (warn), #C0392B (danger)

### Typography
- **Headings**: Orbitron (900, 700, 600)
- **Body**: Rajdhani (600, 500, 400)
- **Data**: JetBrains Mono (600, 500, 400)

### Spacing
- xs: 4px | sm: 8px | md: 12px | lg: 16px | xl: 20px | xxl: 24px | xxxl: 32px

### Borders
- Default: 0.8px gold line
- Cards: gradient top line
- Accent: 3px left bar with gradient

## 💡 Common Tasks

### Change a Color
`lib/theme/jarvis_colors.dart` → Edit hex value → Restart

### Add New Screen
1. Create `lib/screens/new_screen.dart`
2. Export from `lib/screens/index.dart`
3. Add to main.dart `_screens` array

### Customize Typography
`lib/theme/jarvis_theme.dart` → Modify TextTheme → Restart

### Create Widget
1. Create `lib/widgets/new_widget.dart`
2. Use JarvisCard, JarvisChip, etc.
3. Export from `lib/widgets/index.dart`
